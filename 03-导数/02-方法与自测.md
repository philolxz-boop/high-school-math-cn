# 导数：方法与自测

## 解题流程

1. 确定定义域与题目要求的区间。
2. 求导、化简，找出导数为零或不存在的点。
3. 按这些点划分区间，判断导数符号，列出单调区间。
4. 求最值时，比较候选点和允许取到的端点；开区间还要分析边界趋势，不能默认最值存在。

## 自测

1. 求 $f(x)=x^3-2x+1$ 的导数。
2. 求曲线 $y=x^2$ 在 $x=1$ 处的切线。
3. 求 $f(x)=x^2-4x+3$ 在 $[0,3]$ 上的最小值和最大值。
4. 求 $f(x)=\ln x-x$ 的单调区间。

## 答案

1. $f'(x)=3x^2-2$。
2. 斜率为 $2$，切点为 $(1,1)$，故切线为 $y=2x-1$。
3. $f'(x)=2x-4$，在 $x=2$ 处取得最小值 $-1$；比较端点 $f(0)=3,f(3)=0$，最大值为 $3$。
4. 定义域为 $(0,+\infty)$，$f'(x)=1/x-1$，故在 $(0,1)$ 递增，在 $(1,+\infty)$ 递减。
