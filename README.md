# 高中数学知识库

面向中国高中生的开放自主学习知识库。每个专题尽量按“概念 → 公式与性质 → 方法 → 例题 → 自测”的顺序编排，既可查漏补缺，也可用于考前回顾。

本仓库已配置为静态文档站：推送到 GitHub 的 \`main\` 分支后，可由 GitHub Pages 自动发布。发布前需在仓库 **Settings → Pages** 中将发布源设为 **GitHub Actions**。详见 [GitHub Pages 官方指引](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 使用方式

1. 先读每个模块的“总览”，明确知识地图与符号约定。
2. 按曲线逐篇学习；例题先独立完成，再核对思路。
3. 完成模块自测后，将错因记入自己的错题本。

> 记号约定：除非特别说明，椭圆、双曲线均取 \(a>b>0\)，且 \(c^2=a^2-b^2\)（椭圆）、\(c^2=a^2+b^2\)（双曲线）。
