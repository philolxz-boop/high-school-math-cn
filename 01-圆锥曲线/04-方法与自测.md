# 圆锥曲线：统一方法与自测

## 一、直线与圆锥曲线的交点问题

设直线 \(l:y=kx+m\)，代入曲线后得到关于 \(x\) 的二次方程 \(Ax^2+Bx+C=0\)。两交点横坐标为 \(x_1,x_2\) 时：

\[
x_1+x_2=-\frac BA,\qquad x_1x_2=\frac CA.
\]

| 目标 | 优先转化 |
| --- | --- |
| 弦中点横坐标 | \(\frac{x_1+x_2}{2}\) |
| 弦长 | \(|AB|=\sqrt{1+k^2}\,|x_1-x_2|\)，且 \((x_1-x_2)^2=(x_1+x_2)^2-4x_1x_2\) |
| 相交/相切 | 判别式 \(\Delta>0/\Delta=0\) |
| 两弦斜率关系 | 用韦达关系消去交点坐标 |

> 若直线可能竖直，需补充讨论 \(x=x_0\)，或改用一般式 \(ux+vy+w=0\)。

## 二、参数的选择

- **椭圆/双曲线**：已知离心率、焦距时，优先用 \(c=ae\) 与 \(a^2=b^2\pm c^2\)。
- **抛物线**：遇到焦点弦、弦端点，优先使用 \(P(\frac p2t^2,pt)\)。
- **定值与最值**：先将量化成一个变量，再明确变量范围；范围常来自 \(\Delta\ge0\) 或 \(|e|\) 的限制。

## 三、自测（先做再看答案）

1. 椭圆 \(\frac{x^2}{25}+\frac{y^2}{9}=1\) 的焦距与离心率分别是多少？
2. 双曲线 \(\frac{y^2}{16}-\frac{x^2}{9}=1\) 的焦点坐标、渐近线分别是什么？
3. 抛物线 \(x^2=-8y\) 的焦点与准线是什么？
4. 直线 \(y=x+m\) 与椭圆 \(\frac{x^2}{4}+y^2=1\) 有两个不同交点，求 \(m\) 的取值范围。

## 四、答案与关键步骤

1. \(c=\sqrt{25-9}=4\)，焦距 \(2c=8\)，\(e=\frac45\)。
2. \(c=\sqrt{16+9}=5\)，焦点 \((0,\pm5)\)，渐近线 \(y=\pm\frac43x\)。
3. 对比 \(x^2=2py\)，得 \(p=-4\)。焦点 \((0,-2)\)，准线 \(y=2\)。
4. 代入得 \(\frac{x^2}{4}+(x+m)^2=1\)，即 \(5x^2+8mx+4m^2-4=0\)。有两个不同实根：\(\Delta=64m^2-20(4m^2-4)>0\)，故 \(m^2<5\)，即 \(\boxed{-\sqrt5<m<\sqrt5}\)。
