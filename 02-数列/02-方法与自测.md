# 数列：方法与自测

## 常用方法

1. **累加法**：已知 $a_{n+1}-a_n=f(n)$，把从 $1$ 到 $n-1$ 的等式相加，得 $a_n=a_1+\sum_{k=1}^{n-1}f(k)$（$n\ge2$）。
2. **累乘法**：已知 $a_{n+1}/a_n=g(n)$ 且相关项非零时，将比值相乘。
3. **裂项相消**：例如 $1/[n(n+1)]=1/n-1/(n+1)$，求和后中间项消去。
4. **错位相减**：对 $nq^n$ 型求和，可将和式乘以 $q$ 后相减；注意 $q=1$ 需另算。

**例**：$a_1=1$，$a_{n+1}-a_n=2n$。累加得 $a_n=1+2(1+\cdots+n-1)=n^2$，$n=1$ 也成立。

## 自测

1. 等差数列 $a_1=2,d=3$，求 $a_5$ 和 $S_5$。
2. 等比数列 $a_1=3,q=2$，求 $S_4$。
3. 求 $\sum_{n=1}^{10}\frac1{n(n+1)}$。
4. 已知 $S_n=2n^2-n$，求 $a_n$。

## 答案

1. $a_5=14$，$S_5=5(2+14)/2=40$。
2. $S_4=3(1-2^4)/(1-2)=45$。
3. 裂项后为 $1-\frac1{11}=\frac{10}{11}$。
4. $a_1=1$；当 $n\ge2$，$a_n=S_n-S_{n-1}=4n-3$，该式对 $n=1$ 也成立。
